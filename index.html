DevOps Practice 1

Página estática servida por Nginx y desplegada automáticamente mediante un pipeline de GitHub Actions (CI/CD).

1. Repositorio

Control de versiones en GitHub con disparador automático en rama main.

2. CI / CD

GitHub Actions valida la sintaxis y transfiere los archivos mediante SSH/SCP.

3. Servidor Web

Nginx publica el contenido desde /var/www/html/ hacia la web.

Estado: Servidor Nginx operativo. Cada nuevo commit en main actualizará esta página en tiempo real.
